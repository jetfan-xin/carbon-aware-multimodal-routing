# 真实运营方与市场数据替换审计

## 1. 结论

本轮调查没有找到一份可公开下载的“重庆—上海端到端订单表”。找到的是不同层级的运营证据：运营方走廊披露、官方运价指数、同走廊历史班列、上海短驳市场挂价与运营补贴。它们已经替换此前最弱的跨走廊代理和无来源加价，但不能合并成一张真实完成订单。

机器可读来源保存在 [`sources.json`](../data/facility_network/sources.json)，城市级参数在 [`real_world_benchmarks.json`](../data/real_world_benchmarks.json)，设施级逐字段口径在 [`model_inputs.json`](../data/facility_network/model_inputs.json)。历史2022工作簿不被改写。

## 3. 来源能证明什么

### 重庆浩航：当前水运班期、时效与规模

[重庆浩航运输网络](https://cqhaohang.com/col17/)写明重庆—上海水运双向各每周2班、运行10天，周运量700–800 TEU和9,600–11,000吨，并列出10艘345–434 TEU、5,300–7,900吨船舶。这是本模型最直接的当前运营方证据。

它没有公布精确起止码头、订舱等待分布或箱价，所以不能证明“果园港直达洋山240小时且1,130元”。模型把设施映射和价格来源分别标注。

### 民生轮船运营经理：方式比较价

[国家发改委2021年报道](https://cjjjd.ndrc.gov.cn/zhongshuochangjiang/ztbd/202105/t20210521_1280776.htm)引用民生轮船运营经理给出重庆—上海20英尺箱公路约15,000元、铁路4,600元、水路1,400元。它支持运营方口径的比较值，但没有拆解门到门、装卸、短驳或保险等包含项。

### 杨浦—团结村：历史同走廊铁路

[上海市商务委员会2011年资料](https://kab.sww.sh.gov.cn/gzzt/002002/002002001/20110701/A5F63D0F-DDB2-4F75-B433-236CF321971F.html)记录杨浦货站—重庆团结村“五定班列”55–60小时、首发每周1班、40–48箱/列。该资料比成都—上海6天代理更接近本研究走廊，但属于历史服务和不同设施端点。

因此设施库新增杨浦和团结村两个证据节点；数值层将55–60小时映射到果园港—芦潮港时明确标为端点敏感性，不伪装成当前时刻表。

[上海市交通委2021年答复](https://jtw.sh.gov.cn/ysqgkzzdgk/20211113/082afb32cdfa43f7b263e38c8380d087.html)进一步确认，当时重庆属于上海港海铁联运已通达城市，上海终点为芦潮港中心站。但重庆不在答复列出的六条固定循环天天班中；所以该证据只收窄上海端点，不能补成当前日班、当前重庆始发站或取消率。

### 交通运输部：当前市场平均价

[2025年8月长江集装箱运价指数](https://www.mot.gov.cn/yunjiazhishu/changjianghangyunzsfx/202510/P020251010365847531433.pdf)给出重庆—上海20英尺外贸内支线FIO平均1,130元、20英尺内贸CY平均1,547元。出口港衔接案例采用FIO值，并明确它不是门到门或单一运营方报价。

### 上海末端短驳：距离、挂价和补贴分开

[中国口岸协会报道](https://www.caop.org.cn/xinwenzixun/zonghexinwen/2019-02-21/9480.html)描述芦潮港铁路站至洋山约45 km公路短驳。[2026-09-10公开市场挂价](https://www.yiguida.com/informations/20727690)给出芦潮港宜田路至洋山、单个20英尺17–21吨重箱200元。仓库不保存页面中的联系电话；200元仅作为一个中央敏感性观察。

[上海市2025–2026海铁联运补贴方案](https://jtw.sh.gov.cn/cmsres/10/1081da9134714665980c56ead5b1e7bf/3385e02038297d10a835787a7065df27.pdf)给符合条件的末端运输运营方重箱180元/TEU、空箱130元/TEU支持。它不是客户运价，模型没有用“200−180”制造20元短驳成本。

[上海市2024年度项目绩效自评](https://jtw.sh.gov.cn/cmsres/a2/a2719ba31b574ed88839e7d57a7927c3/4ba244331fbecd91178a110d5ea757cc.pdf)还给出“铁路至港口转运换装1小时完成率大于60%”。模型据此把处理中央值从2小时改为1小时；闸口和班次等待仍没有分布，继续保留1/4/8小时敏感性假设。

## 4. 负面调查结果

民生轮船官网可下载的2024运价表和2026班期表经过隔离读取；内容是日本、台湾等国际线，没有重庆—上海长江内支线的可用时刻或报价。因此它们未复制进仓库，也没有被错误引用为本走廊证据。

交通运输部2024多式联运案例集确认成都城厢—上海芦潮港X9632每日开行和“一箱到底”，可证明现实中存在公铁港衔接模式，但不能直接替代重庆—上海铁路时效或价格。

## 5. 更新后的数值结果

城市级15吨中央模型在97.49元/tCO2e下：铁路57.5 h/4,607.60元，快水运204 h/1,470.16元，普通水运240 h/1,200.16元，公路96 h/15,188.38元。铁路对快水运和普通水运的结构碳价切换点约为4,986.64和5,407.38元/tCO2e。

设施级模型显式加入芦潮港短驳后：铁公联运64.75 h、运输加换装4,830元、131.205 kg；快水运204 h、1,400元、719.70 kg；普通水运240 h、1,130元、719.70 kg；公路96 h、15,000元、1,932.30 kg。铁路对两种水运的结构切换点约为5,828和6,287元/tCO2e。

两组阈值不同，因为设施级铁路包含45 km公路短驳、处理、等待和换装成本排放。两者都只是定义模型内的敏感性边界，不是现实碳税预测。

## 6. 尚不能替换的字段

1. 当前重庆铁路真实始发站、班次、取消率和门到港报价；上海端已有2021年芦潮港证据，但不是当前班次证明；
2. 4,600元铁路比较值是否已包含上海末端短驳；
3. 芦潮港—洋山合同价、完成订单和完整闸口等待分布；处理环节仅有“1小时完成率大于60%”边界；
4. 当前水运精确起止港、订舱等待、准班率以及浩航自有报价；
5. 真实订单OD、箱型、重量、截止时间、货类和可用班期；
6. 具体车型、列车编组、船型、装载率和空驶率对应的实测排放。

因此当前版本适合证据可追溯的路线权衡和算法实验，不适合运营报价、实时调度或声称已经处理企业级真实订单。
