# 运营数据校准的走廊情景设计

## 1. 目的和证据边界

本实验不是把公开网页拼成“真实订单数据库”，而是用运营方披露、政府市场指数和同走廊历史运行记录替换可以替换的假设。2022历史快照保持不变；当前校准层单独保存在 [`real_world_benchmarks.json`](../data/real_world_benchmarks.json)。

字段按证据粒度区分：运营方比较值、官方市场平均值、同走廊历史运行、团队采集距离、单条市场挂价和模型假设。不同年份、费用范围和端点不被静默统一。

## 2. 已替换的假设

- 公路、铁路、水路20英尺箱比较值15,000/4,600/1,400元来自民生轮船运营经理的走廊比较，不再笼统标成政府实测运价。
- 铁路时效由成都—上海6天代理改为上海杨浦—重庆团结村历史“五定班列”55–60小时。它是同走廊历史运行证据，不证明当前果园港—芦潮港仍有同等班列。
- 快水运删除原先无来源的10%溢价，使用1,400元走廊比较值；8–9天仍来自重庆交通部门公布的快线范围。
- 普通水运采用浩航公开的当前10天运行时间，并记录每周双向各2班、700–800 TEU和9,600–11,000吨周运量；价格采用交通运输部2025年8月重庆—上海20英尺FIO平均1,130元。班期等待未知，不并入10天航程。
- 重庆—上海铁路距离纠正为团队工作簿明确行的1,733 km；1,754 km是重庆—张家港，不是上海。

## 3. 仍保留的假设

- 公路72/96/120小时仍是3–5天敏感性带；尚未找到可公开核验的承运调度记录。
- 10/15/20吨是载重敏感性，不是公开订单的实际载重分布。
- `p10/p50/p90` 是实验标签。铁路55/57.5/60来自历史范围，不是统计分位数；普通水运三档均为240小时，因为公开资料没有分布。
- 城市级端点与果园港、芦潮港、洋山等具体设施的映射，以及23城合成图上的按距离分摊，仍是模型假设。
- 全国碳市场价格只作为影子价格；模型不声称货运企业直接缴纳这些碳费。

## 4. 模型和累计碳价

`Network` 支持平行服务、每票报价、显式运行时间、处理时间与班次等待。多票组合先汇总排放，再对累计排放应用分段价格：

```text
C_carbon(E) = sum_k rate_k * max(0, min(E, upper_k) - lower_k)
```

这样不会因拆单而反复享受第一档价格。

## 5. 实验矩阵

- 截止时间：48、55、60、72、96、120、192、204、216、240、276、360小时；
- 碳价：0、50、62.36、74.63、97.49、106、150、300、1,000、5,000、6,000元/tCO2e；
- 载重：10、15、20吨/20英尺箱；
- 时间：三种证据/敏感性档；
- 组合规模：1、10、50、100、250票同质20英尺箱。

完整确定性网格为12 × 11 × 3 × 3 = 1,188格。48和55小时在15吨中央档故意保留为不可行情景，用于验证硬截止行为。

## 6. 五种算法的公平比较

从可行边界、快水运/普通水运开放点和碳价切换附近选15个场景。固定、自适应、灾变、自适应+灾变、图启发式初始化五种方法各运行30个种子；每个GA使用16个个体、25代，即400次候选评价。

图启发式初始化先运行成本—时间标签搜索，其展开状态数单独报告，不计入400次GA评价。它的首代优势不能归因于选择、交叉或变异。

运行命令、CSV、JSON和SVG见 [`real-case-sensitivity`](../benchmarks/real-case-sensitivity/README.md)。逐字段替换和仍缺数据见 [`OPERATOR_DATA_REPLACEMENT_CN.md`](OPERATOR_DATA_REPLACEMENT_CN.md)。
