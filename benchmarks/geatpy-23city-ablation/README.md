# Real-Geatpy 23-city ablation

Regenerate from the repository root with:

```bash
sh tools/run_geatpy_experiment.sh
```

The directory contains 150 Geatpy 2.7.0 runs (five variants, 30 seeds), a full JSON record, a flat CSV summary, three statistical SVG figures and one computed-route SVG. All data are synthetic calibrated inputs. A second independent run produced byte-identical copies of all six generated files.

Interpretation and limitations are documented in [`docs/GEATPY_RESULTS_ANALYSIS_CN.md`](../../docs/GEATPY_RESULTS_ANALYSIS_CN.md).
