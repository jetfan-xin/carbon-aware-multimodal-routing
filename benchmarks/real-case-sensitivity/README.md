# Official-corridor sensitivity benchmark

This directory is generated by:

```bash
python3 -B tools/run_real_case_sensitivity.py \
  --output-dir benchmarks/real-case-sensitivity
```

It combines operator-reported comparisons, an official market index, historical same-corridor operations and separately labelled assumptions. It is not a transaction dataset and does not claim that freight is directly covered by China's national ETS.

## Scope

- `scenario-grid.csv`: 1,188 deterministic combinations (12 deadlines × 11 carbon prices × 3 payloads × 3 time cases).
- `portfolio-grid.csv`: 60 exact homogeneous-portfolio cases using the historical progressive carbon brackets once on aggregate emissions; infeasible deadlines remain explicit.
- `selected-scenarios.json`: 15 deadline/carbon boundary and stress scenarios.
- `algorithm-runs.csv`: 2,250 runs (15 scenarios × 5 methods × 30 seeds).
- `algorithm-traces.csv`: generation-level traces for every run.
- `results.json`: experiment definition, caveats and summary.
- SVG files: route phase, cost components, emissions trade-off, portfolio carbon, algorithm quality and three computed routes.

The 23-city algorithm comparison uses a synthetic topology whose end-to-end values are allocated over edges in proportion to model distance. That allocation, road time, endpoint mappings and payloads are assumptions. Rail time is historical same-corridor evidence, while current water time and volume are operator-reported. Their dates and price scopes are not claimed to be identical.
